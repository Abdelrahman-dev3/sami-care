## لماذا يوجد نمطا عرض؟

المشروع أصله موقع HTML ثابت، ويجري ترحيله إلى Vue **صفحة بصفحة**
مع الحفاظ على سلوك الصفحات القديمة أثناء الترحيل.

| النمط | الصفحات | الحالة |
|---|---|---|
| مكوّنات Vue | الرئيسية · الخدمات · تفاصيل الخدمة | ✅ مُرحَّلة |
| `LegacyPage` | الحجز · المتجر · الإهداء · الباقات · الفروع · تواصل · مستلم الهدية | ⏳ قيد الترحيل |

**اتجاه الترحيل:** كل صفحة قديمة تُفكَّك تدريجيًا إلى مكوّنات + بيانات في `src/data/`.

## كيف يعمل `LegacyPage`

```js
import source from '@/legacy/booking.html?raw'
```

Vite يستورد الملف كنص، ثم المكوّن:

1. يحلّل النص بـ `DOMParser`
2. ينزع وسوم `<script>` من الماركب
3. يحقن كتل `<style>` في `<head>` (ويزيلها عند مغادرة الصفحة)
4. يطبّق `class` و `style` الخاصة بـ `<body>` الأصلي
5. ينفّذ السكربتات بعد التركيب، **مع تغليف** `addEventListener`
   لتُنظَّف كل المستمعات تلقائيًا عند إزالة المكوّن
6. يعترض نقرات `<a href>` الداخلية ويحوّلها لـ `router.push`

### لماذا تُحوَّل `const` إلى `var` قبل التنفيذ؟

السكربتات تُنفَّذ في **النطاق العام** (لأن بعض الصفحات تعتمد على `onclick` داخل الـ HTML،
وهذه تُنفَّذ في النطاق العام حصرًا).

لكن عدة صفحات تُعلن نفس الأسماء (`S` · `BRANCHES` · `$` · `rs` · `PKGS` ...) بـ `const`.
عند الانتقال من صفحة لأخرى داخل نفس المستند، إعادة الإعلان ترمي:

```
SyntaxError: Identifier 'S' has already been declared
```

فيتوقف السكربت بالكامل وتظهر الصفحة بلا وظائف. لذلك يحوّل `runLegacyScript`
إعلانات المستوى الأعلى إلى `var` (وهي قابلة لإعادة الإعلان).

> هذا التحويل **لا يمسّ أي شيء يخص العرض أو الأنماط.**

## تعارض المعرّفات مع جذر Vue

`index.html` فيه `<div id="app">` وهو نقطة تركيب Vue.

صفحتا الإهداء والباقات كانتا تستخدمان **نفس المعرّف** لحاويتهما الداخلية.
عند عرضهما داخل التطبيق يصبح في المستند عنصران بنفس المعرّف،
و `document.querySelector('#app')` يُرجع **الأول** = جذر Vue —
فيكتب السكربت محتواه فوق التطبيق كله ويمحو الهيدر.

**الحل:** أُعيدت تسميتهما إلى `giftsApp` و `pkgApp`.

> ⚠️ **قاعدة:** أي صفحة قديمة جديدة يجب ألا تستخدم `id="app"`.

كل صفحة legacy لها كائن `S` خاص. المشترك الوحيد هو `localStorage['samiSiteBranch']`.

### 5. السلة غير محفوظة 🟡
سلة المتجر في ذاكرة الصفحة وتضيع عند إعادة التحميل.

### 6. نتيجة عجلة الحظ تُحسب في المتصفح 🔴
ثغرة أمنية — يجب نقل الحساب للخادم.

### 7. أنماط `home.css` متراكمة 🟡
نما تراكميًا وفيه استخدام كثيف لـ `!important` وطبقات متعاقبة.
أي إعادة تنظيم له تحتاج اختبارًا بصريًا دقيقًا لكل الصفحات.

| مستلم الهدية | ✅ **مُرحَّلة** | كانت مجرد تحويل |
| **المتجر** | ✅ **مُرحَّل بالكامل** | 6 مكوّنات + حالة تفاعلية |
| **الإهداء** | ✅ **مُرحَّل بالكامل** | 9 مكوّنات + حالة تفاعلية |

| **الحجز** | ✅ **مُرحَّلة بالكامل** | 8 مكوّنات · 5 خطوات |

### أدوات الترحيل

**`usePageStyles(css, name)`** — يحقن أنماط الصفحة عند الدخول ويزيلها عند الخروج.
ضروري لأن أنماط الصفحات القديمة تحتوي محدّدات عامة (`:root` · `body` · `header`)
لا يمكن جعلها `scoped` ولا تركها عامة.

**`useInternalLinks(rootRef)`** — يوجّه روابط `<a>` الداخلية عبر vue-router
دون استبدالها بـ `RouterLink` (الذي يضيف أصنافًا قد تغيّر الشكل).

### منهجية الترحيل المتَّبعة

1. استخراج الأنماط حرفيًا إلى `src/assets/styles/pages/<page>.css`
2. نقل ماركب `<body>` كما هو إلى `<template>` (بدون إعادة كتابة)
3. استبدال المنطق المحقون بالمكوّنات المشتركة (`useServiceLocation` ...)
4. **إثبات التطابق:** مقارنة بصمة الماركب والأنماط قبل وبعد

> الخطوة 4 غير قابلة للتفاوض — أي ترحيل بدون إثبات تطابق يخاطر بتغيير التصميم.

### الصفحات الأربع المتبقية — لماذا تحتاج وقتًا

|---|---|---|---|
| الحجز | 52K | 35 | 174 |

### ملاحظة على `SHAPES`

تُنتج رسوم SVG كنصوص وتُستخدم عبر `v-html`.
هذا **مقصود** — إعادة كتابتها كقوالب Vue تخاطر باختلاف في الماركب الناتج.

### درس مهم من ترحيل `ProductCard`

المحاولة الأولى غلّفت الـ SVG داخل `<span v-html>`. هذا **يغيّر بنية DOM**:
`.pcard .pimg` هي `display:grid`، فالغلاف كان سيصبح عنصر الشبكة بدل الـ SVG نفسه.

**الحل:** دالة `shapeParts(name, size)` تفصل ناتج `SHAPES` إلى `viewBox` + محتوى داخلي،
فيُرسم الـ SVG كعنصر Vue حقيقي بلا غلاف:

```vue
<svg class="prod" :width="size" :height="size" :viewBox="shape.viewBox" v-html="shape.inner"></svg>
```

**قاعدة عامة للترحيل:** لا تُدخل أي عنصر غلاف لم يكن في الأصل —
حتى لو بدا محايدًا، فقد يكون أبًا في flex/grid أو يطابق محدّدًا موجودًا.

**التحقق:** 64 حالة (16 منتج × grid/list × مفضل/غير مفضل) — بنية DOM مطابقة حرفيًا.

### مسارات الأصول في المكوّنات المُرحَّلة ⚠️

عند نقل ماركب من صفحة HTML قديمة إلى مكوّن Vue، **يجب تحويل مسارات الأصول
النسبية إلى مطلقة**:

```diff
- <img src="logo.png">      ← يعمل في HTML، ويكسر بناء Vite
+ <img src="/logo.png">     ← الصحيح داخل مكوّن Vue
```

**السبب:** Vite يحلّل `src="..."` النسبي كملف مجاور للمكوّن نفسه،
بينما الملف موجود في `public/`. الخطأ الناتج:

```
[plugin:vite:import-analysis] Failed to resolve import "logo.png"
```

الملفات داخل `src/legacy/` لا تتأثر لأنها تُحقن كنص خام دون تحليل.

> السمات الديناميكية (`:src="item.image"`) لا تتأثر — Vite لا يحلّلها وقت البناء.

### النوافذ المنبثقة يجب أن تُنقل إلى `body`

`LocationPicker` يستخدم `<Teleport to="body">`.

**السبب:** أنماط الصفحات المُرحَّلة تُحقن عالميًا وتحتوي عناصر بـ
`position:sticky` و `z-index` مرتفع. أي عنصر منها قد يُنشئ
**stacking context** يحبس النافذة داخله مهما رفعنا `z-index` الخاص بها.

`Teleport` ينقل النافذة إلى `<body>` مباشرة فتخرج من أي سياق كهذا.

> ملاحظة: عند استخدام `Teleport` **لا تستخدم `<style scoped>`** —
> العنصر يصبح خارج شجرة المكوّن فلن تنطبق عليه الأنماط المحصورة.
> بدلًا من ذلك: أنماط عامة بأسماء أصناف مسبوقة (هنا كلها `.loc-*`).

### اعتراض الروابط يجب ألا يبتلع نقرات الأزرار

`useInternalLinks` يتجاهل أي نقرة مصدرها `<button>`:

```js
if (el.closest('button')) return
```

وإلا فقد يلتقط المعترضُ نقرةً موجّهة لزر داخل منطقة تحتوي روابط،
ويستدعي `preventDefault` قبل أن يصل الحدث إلى معالج الزر.

كما يتعامل مع كون `event.target` عنصر SVG (قد لا يملك `closest`):

```js
const el = t && typeof t.closest === 'function' ? t : (t && t.parentElement)
```

### الوسوم الفارغة يجب إغلاقها ذاتيًا 🔴

أهم فخ عند نقل ماركب HTML إلى قالب Vue:

```diff
- <input type="text" id="cName">     ← صالح في HTML، يكسر قالب Vue
+ <input type="text" id="cName" />   ← الصحيح
```

**السبب:** مترجم Vue يتعامل مع `<input>` غير المغلق كوسم **مفتوح**،
فيبتلع كل ما بعده داخله وتنهار بنية الصفحة — دون رسالة خطأ واضحة أحيانًا.

**الوسوم المتأثرة:**
`input` · `img` · `br` · `hr` · `meta` · `link` · `source` · `area` · `base` · `col` · `embed` · `track` · `wbr`

**فحص سريع بعد أي ترحيل:**

```bash
grep -oE '<(input|img|br|hr)[^>]*[^/]>' src/views/*.vue src/components/**/*.vue
```

> أي نتيجة تعني وسمًا غير مغلق يجب إصلاحه.

### الاقتباسات المهروبة داخل `{{ }}` 🔴

خطأ ينشأ عند توليد ملفات `.vue` عبر سكربت:

```diff
- {{ current ? current.name : \'اختر المكان\' }}   ← يكسر المترجم
+ {{ current ? current.name : 'اختر المكان' }}     ← الصحيح
```

داخل `{{ }}` تُكتب الاقتباسات عادية. الهروب (`\'`) صالح فقط داخل
نص JavaScript محصور في سمة، وحتى هناك يُفضّل تجنّبه.

**الأفضل:** استخدم مكوّن `SIcon` بدل `v-html` بنصوص مهروبة:

```vue
<!-- بدلًا من -->
<span v-html="svg('<path d=\'M6 9l6 6 6-6\'/>', 15)"></span>

<!-- استخدم -->
<SIcon inner='<path d="M6 9l6 6 6-6"/>' :size="15" />
```

### فرق مقبول: سمة `value` مقابل `v-model`

عند ترحيل حقول الإدخال:

```diff
- <input value="${S.name}">        ← الأصل: سمة في الماركب
+ <input v-model="state.name" />   ← Vue: خاصية DOM
```

الماركب الناتج يختلف (لا تظهر سمة `value`) لكن **السلوك والشكل متطابقان**،
بشرط عدم وجود محدّد CSS يعتمد على السمة مثل `[value]` أو `:placeholder-shown`.

**تحقّق قبل القبول:**

```bash
grep -oE '\[value[^]]*\]|placeholder-shown' src/assets/styles/pages/<page>.css
```

> إن ظهرت نتيجة، لا يمكن الاكتفاء بـ `v-model` — يجب ربط `:value` أيضًا.

## نظام الحركة

`src/assets/styles/motion.css` — يُحمَّل عالميًا من `main.js`.

| الطبقة | ما تفعله |
|---|---|
| انتقال الصفحات | `<Transition name="page">` حول `RouterView` — دخول بانزلاق وخروج بتلاشٍ |
| الكشف عند التمرير | `[data-reveal]` + `useScrollReveal()` عبر `IntersectionObserver` |
| تفاعلات دقيقة | رفع البطاقات · لمعان على الأزرار الذهبية · تسطير روابط القائمة |
| الصفحة الرئيسية | تتابع عناصر الهيرو · عوم الصورة · توهّج نابض · امتداد خطوط العناوين |

### الاستخدام

```html
<section data-reveal>…</section>
<article data-reveal="right" data-reveal-delay="2">…</article>
```

الاتجاهات: (افتراضي = من أسفل) · `right` · `left` · `zoom`
التأخير: `1` إلى `5` (‎0.08s لكل درجة)

### ملاحظات

- `useScrollReveal()` يُستدعى **مرة واحدة في `App.vue`** ويغطي كل الصفحات.
- يستخدم `MutationObserver` لالتقاط العناصر التي تُضاف لاحقًا
  (عند تغيير خطوة في رحلة الحجز مثلًا).
- **الهيرو مستثنى** من الكشف لأن له حركة دخول خاصة.
- كل الحركة تُعطَّل تلقائيًا عند `prefers-reduced-motion: reduce`.
