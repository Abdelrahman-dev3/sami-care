# Wepsami Vue

نسخة Vue متعددة الصفحات لموقع عناية سامي، مع الحفاظ على التصميم والوظائف الأصلية.

## التشغيل

```bash
npm install
npm run dev
```

في التطوير، Vite يوجه طلبات `/api` تلقائيا إلى `http://127.0.0.1:8000`.
لو الواجهة والباك اند على دومينات مختلفة، اضبط `VITE_API_BASE_URL`.

## البناء

```bash
npm run build
```

## المسارات

- `/` الصفحة الرئيسية
- `/booking` الحجز
- `/store` المتجر
- `/gifts` الهدايا
- `/packages-gifts` الباقات والإهداء
- `/branches` الفروع
- `/contact` التواصل
- `/gift-recipient` مستلم الهدية
- `/blog` المدونة
- `/blog/:slug` تفاصيل المدونة

## التقسيم

- `src/views`: صفحة مستقلة لكل مسار.
- `src/router`: جميع مسارات Vue والروابط المتوافقة مع أسماء HTML القديمة.
- `src/components/legacy`: طبقة مشتركة تحفظ السلوك والتصميم أثناء مرحلة النقل.
- `src/legacy`: النسخ الأصلية لكل صفحة لضمان عدم فقد أي محتوى أو وظيفة.
- `public`: الصور والملفات العامة.

تم تحميل الصفحات عند الطلب (lazy loading) حتى لا يُحمّل المتصفح المشروع بالكامل عند فتح أول صفحة.
