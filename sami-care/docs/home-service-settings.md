# إعداد الخدمة المنزلية

- شغّل `php artisan migrate` من مجلد `sami-care` بعد توفير اعتماديات Composer.
- حدد رسوم الزيارة لكل مدينة من إدارة المدن (بالريال، قبل ضريبة القيمة المضافة).
- من صفحة إدارة الخدمة المنزلية فعّل الخدمة وحدد مركز التغطية ونصف القطر على خرائط جوجل. تعتمد الخريطة على `google_maps_key` الموجود في إعدادات النظام وتفعيل Maps JavaScript API للمفتاح.
- التغطية دائرة يمكن نقل مركزها بالنقر على الخريطة أو سحبها وتغيير نصف قطرها. القيم الافتراضية تحافظ على تشغيل الخدمة وتبدأ بمركز جدة ونصف قطر 50 كم؛ راجعها قبل التشغيل الفعلي.
- يختار العميل المدينة وموقع الزيارة. يتحقق الخادم من أن الموقع داخل الدائرة وأن المدينة نشطة.
- تحفظ المدينة والإحداثيات ورسوم الزيارة في الحجز. تضاف الرسوم مرة واحدة فقط لأول خدمة في طلب الحجز، ضمن سعرها المحفوظ، وبالتالي تدخل في حساب السلة والدفع والضريبة الحالي. تعرض الواجهة الرسوم منفصلة في ملخص الحجز.
- إيقاف الخدمة يخفي خياراتها وبطاقاتها من الواجهة ويمنع إنشاء حجز منزلي جديد.

التحقق: `php tests/Unit/HomeServiceCoverageSmoke.php` و `npm run build` داخل `front-end/project-sami`.
