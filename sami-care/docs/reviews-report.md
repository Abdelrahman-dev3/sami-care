# تقييمات الفروع والخدمات وتقرير التقييمات

تعرض صفحة آراء العملاء تقييم الفرع باسمه وتقييم كل خدمة والموظف وتعليق العميل. أضيف رابط التقرير من هذه الصفحة، ورابط «تقرير التقييمات» في قسم التقارير. التقرير يستخدم صلاحية `overall_booking_report` مثل تقارير العملاء والإحالات الحالية.

الفلاتر: تاريخ إرسال التقييم، النوع، الفرع، عدد النجوم، الاعتماد، والظهور. تعرض بطاقات الإحصاءات العدد والمتوسط لكل نوع على جميع النتائج المطابقة، بينما الجدول مقسم إلى صفحات. التقييمات المخفية وغير المعتمدة تظهر للإدارة افتراضياً ولا يغيّر التقرير اعتمادها أو نشرها.

كل تقييم خدمة أو موظف ضمن الحجز يمثل تصويتاً مستقلاً في التقرير العام. التقييم الصريح للفرع لا يكرر معه التقييم العام للحجز. آراء الحجوزات القديمة التي لا تحتوي تقييماً صريحاً للفرع تبقى تحت «الحجوزات العامة القديمة». تشمل النتائج تقييمات الموظفين القديمة دون تكرار القديم عند وجود تقييم حديث لنفس العميل والحجز والموظف.

تظل التقييمات محفوظة عند حذف الحجز أو العميل، وتظهر معرفات الخدمة والموظف عند غياب بيانات الاسم. لا يحتاج التقرير migration جديداً أو بناء Vue؛ يستخدم جداول التقييمات وBlade الموجودة. يلزم تطبيق الترحيلات السابقة للمشروع على بيئة التشغيل.

الاختبار: `php tests/Unit/ReviewReportSmoke.php`، ويتحقق من 13 حالة. نجح فحص PHP، لكن فتح الداشبورد والتحقق عبر قاعدة البيانات يتطلبان اعتماديات Laravel غير المتوفرة حالياً في vendor.
