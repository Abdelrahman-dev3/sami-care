# تأكيد وصول العميل

- من قائمة الداشبورد «تأكيد وصول العملاء» أو زر «تأكيد الوصول وQR» في صفحة الحجوزات، ابحث برقم الحجز ثم فعّل مفتاح الوصول.
- زر «عرض البيانات وQR» يعرض العميل والفرع والموعد والخدمات، والرمز الخاص بالحجز.
- يظهر الرمز أيضاً داخل حجوزات العميل في الفرونت، في نسختي الكمبيوتر والموبايل. يعرضه العميل لموظف الاستقبال ليمسحه ويؤكد وصوله.
- يمكن المسح بكاميرا الهاتف العادية، أو من قسم المسح في صفحة الوصول في المتصفحات التي تدعم `BarcodeDetector` على HTTPS. عند عدم دعمه يمكن فتح الرمز بكاميرا الهاتف أو لصق رابط المسح.
- الرمز يحمل رابطاً موقعاً لبيانات الحجز. فتحه يتطلب تسجيل دخول موظف لديه صلاحية `edit_booking`. لا يرسل اسم العميل أو بياناته إلى خدمة خارجية لتوليد QR.
- بعد المسح، يراجع الموظف بيانات الحجز ويضغط «تأكيد وصول العميل». فتح الرابط وحده لا يغير البيانات.
- يسجل النظام وقت الوصول والموظف وطريقة التأكيد (`qr` أو `manual`). تكرار التأكيد يحافظ على الوقت والموظف الأصليين. يمكن إلغاء التأكيد يدوياً ما دام الحجز لم ينتهِ أو يُلغَ.
- تأكيد الوصول مستقل عن حالة الحجز `check_in` وعن حالة الدفع؛ لا يغير موعد الحجز أو حالة الدفع.

## التفعيل

من مجلد Laravel بعد توفير dependencies:

```sh
php artisan migrate --force
php artisan optimize:clear
php artisan test --filter=BookingArrivalTest
```

توجد migration جديدة لحقول `arrived_at`, `arrival_confirmed_by`, `arrival_source`. يجب تطبيقها قبل استخدام الصفحات الجديدة.

نسخة الفرونت المبنية موجودة في `front-end/project-sami/dist`، ويمكن إعادة بنائها باستخدام `npm run build` من مجلد الفرونت. واجهة الأدمن الجديدة تستخدم Blade وJavaScript مباشرة ولا تحتاج إعادة بناء حزمة الأدمن.
